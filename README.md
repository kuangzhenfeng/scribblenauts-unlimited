# 涂鸦冒险家 无限（中文复刻）

> 全新项目，以 Phaser 4 为引擎重制《涂鸦冒险家 无限》核心玩法，追求 Awwwards 级视觉。

## 项目定位

2D 涂鸦风文字解谜游戏。玩家在魔法笔记本输入任意词（中/英），对应物体即出现在游戏世界；可叠加形容词修改物体；物体间基于属性标签与规则引擎进行深度交互。

- 基础美术为 sprite atlas（统一 sprite + 运行期 `setTint` 染色，对齐行业做法：每对象一套美术 + tint，非每颜色变体画新图）；角色/动物/载具/特效及基础物品、装饰已完成背景去除、透明边缘颜色扩展和 atlas JSON 生成的 `public/assets/sprites/` 素材，`scripts/sprite-specs.js` 共 604 个规格。sprite 注册从 `SPRITE_SPECS` 派生：多帧对象（maxwell/bird/fish/tentacled/car/fire/water/steam/starite）显式注册帧序列，单帧静态物件由 `spriteRenderers.ts` 遍历 `SPRITE_SPECS` 自动注册，spec 新增条目即自动入册，无手工清单漂移。renderer===id 原则：creature 词条 renderer 直接等于自身 id（dog/cat/dragon/human/ghost...），每物种独立 sprite atlas，形态区分度由独立美术解决；vector paper-doll 路由已废弃删除。缺图对象由 `EntityGraphics` 按纹理存在性回退兜底绘制（占位矩形 + 粗黑描边 + 白色问号）。词库≫独立美术资源：近义词条可共享同一 atlas（如 amulet 复用 gem、totem-mini 复用 totem），并经 aliases 扩充可识别词汇
- 游戏内远景背景已接入 GPT 生图双板：每个主关卡拥有独立远板固定屏天空盒（`scrollFactor 0,0`）与独立低透明度近板水平无缝视差中景（`scrollFactorX 0.5, scrollFactorY 1`，垂直锚定地面），共 41 套区域背景素材；`theme` 只负责地面/功能层调色，缺图时自动回退程序化分层绘制。世界场景首帧统一角色脚底、物理地面与可玩带接触层，首屏包含可交互目标并按主题校准对比度，同时降低近板与前景装饰对比度、加入轻微环境摆动，避免交互实体被背景吞没；游玩 HUD 对齐原版三项资源栏与金色挑战槽，NPC 挑战文本按 NPC 位置显示为双层金色任务气泡并自动避让人物，Starite Vision 默认收起为右上角工具栏入口，窄屏自动错层，场景重进时清理旧浮层；选关页路线节点与卡片统一暖金纸片舞台视觉；NPC 对话气泡提高字号并避让角色活动线，暂停层保持真正居中，传送门补充手绘石块细节；提示词见 `docs/background-prompts.md`
- 主世界支持滚轮缩放（0.75–1.5 倍）：缩放保持视口中心，固定屏远景持续覆盖屏幕，世界特效与对话气泡坐标同步更新
- 双语闭集分词（中/英输入解析，零通用 NLP 依赖）
- 声明式规则引擎 + 三重限流对抗反应链
- 装备组合：手持枪械/弩/弹弓/加农炮按 `X` 连续发射真实投射物；玩家和 NPC 的服装均可按脸部/头部/身体/手部/腿部/脚部/背部/全身部位自动附着，翅膀与喷气背包提供飞行，弹簧鞋增强跳跃，全身套装与其他服装互斥且穿戴物不参与物理碰撞；手持武器、穿戴能力与骑乘飞行坐骑可同时生效，投射物命中生物沿用伤害规则
- 程序化粒子（火/蒸汽/墨迹飞溅）+ Filter 后处理（Glow/Vignette/ColorMatrix），传送门暖光使用轻量程序化图形避免全屏滤镜合成，纸纹使用 WebGL 安全的低透明度叠加，燃烧实体 Glow 按状态幂等挂载并及时移除；HUD 数据未变化时不重复重建 DOM
- 涂鸦手绘纸片质感：统一圆角纸张面板 + 纸片落地软影 + 低分辨率静态纹理纸纹颗粒，自托管无衬线字体 UI
- 分层视差环境：天空/远山/云/中景/地面/前景草丛，`setScrollFactor` 驱动，零 per-frame 重绘；主题色板覆盖丛林/洞穴/雪原/沙漠/火山
- 生成动效：物体从笔记本飞出 + 墨迹飞溅 + pop-in 缩放（复用 `FxParticles.burst`）
- Maxwell 专属渲染器（罗纹帽/背包带/表情眼/走路 bounce/跳跃 squash/stretch）
- Starite 体系：挑战完成时 5 角星从世界点飞向 HUD；关卡 Starite 以发光实体呈现，Object Shard 按 Living/Food/Vehicle/Music/Tech/Weapon/Clothes/Misc 八类跨关收集，10 个兑换 1 个 Starite，并在 106 个 Starite 全收集时展示独立家庭档案里程碑
- 标题页：生成式手绘全屏 key art 直接承载 Logo、背景、Maxwell 与场景道具，横屏/竖屏按方向切换专用构图，采用浅色低对比度处理，DOM 仅叠加按钮
- 标题页、选关页、世界 HUD、笔记本、系统面板与简易问答统一为原版纸片视觉，支持窄屏/键盘焦点/reduced-motion；标题页仅通过明确入口或键盘操作进入主世界，点击空白区域不会误切场景
- 音乐：跨场景 Web Audio 合成 5 声部循环旋律（主旋律 + 和声 + 低音 + 琶音 + 打击），模拟钟琴/马林巴/拨弦/木管/低音拨弦音色（OfflineAudioContext 预渲染 AudioBuffer 缓存复用）；每个主关卡按唯一 `bgm` 键生成独立旋律、和弦、节拍与配器，禁止跨关复用背景音乐，并支持静音
- 音效：生成、跳跃、着地、拾取、挑战完成、Starite 收集、UI 点击、错误提示等全程合成音效，复用音乐 AudioContext 与音色库
- 设置页：独立设置场景，提供界面语言（中文/English，切换即时生效并持久化，覆盖 UI 文案与游戏内 NPC 对话/物体名/题面）、音乐/音效音量滑块（实时生效）、主静音开关（同时控制音乐与音效）、屏幕方向（跟随设备/锁定横屏）、触屏控制（自动/开启/关闭）、难度档位（基础/进阶/大师）与难度定义方式（游戏内等级档/词频启发式档）切换（并展示两种标准下各档位的词库分布与题目分布）、过滤 A1 基础题（默认开启，排除答案全为 CEFR A1 级词汇的题目）、题目种子查看/输入/刷新、清除存档，偏好 localStorage 持久化跨会话记忆
- 简易问答模式：面向手机优先、兼顾电脑横屏的漫画词汇召唤玩法。标题页"简易问答"按钮进入，界面采用简易模式专属的透明顶栏 / 纯文字横向任务条 / 响应式自然情境 / 笔记本输入台组成：整屏背景图连续铺满画布，顶栏控制悬浮其上，保留返回、回合、得分、连胜、最高分、换题与纯图标词频设置按钮，状态板按层级组织即时进度；设置弹层支持等级档/词频标准、基础/进阶/大师难度、界面语言和随机种子重置（即时重建或刷新问答并持久化）；每次进入简易模式生成独立会话种子，避免复用上一轮题序；任务条仅展示题面与有意义的提示文字，不包含装饰图标、泛化操作标签或 Enter 提示；背景采用上半屏安全区 + 下半屏低信息草地的故事书自然情境，重要装饰只放在左右边缘，键盘无论遮挡多高都不截断核心对象；下屏改为与主世界 Notebook 同源的悬浮米白纸片输入台，键帽保持高对比实体纸面且不叠加背景图，生成键与主世界笔记本统一使用绿色动作色，输入显示保留形容词与名词之间的空格，切换界面语言只刷新文案并保留当前题目与回合，答对/答错由任务条与提示条即时反馈，横屏空间足够时输入台贴底、空间不足时内部滚动避让题面。随机生物出题（每题换一个生物），玩家输入形容词+名词生成物品，答对积分与连胜各+1并切下一题，答错连胜归零且保留当前题，物品持续 3 回合后消失；换题与切难度重置当前分数/连胜，最高分持久化。
- 原版辅助系统：关卡采用种子驱动的随机布局，每次存档拥有不同的预生成物体、NPC 位置和环境装饰；同时支持多阶段/计数/区域/NPC 状态挑战，完成 Starite 门槛后按顺序解锁新区域。世界内提供魔法背包（最近使用、频次、收藏、搜索、再次生成）、物体编辑器（中英文名称/别名、形容词、颜色、编辑/复制/删除）、世界地图、Merit Board、Object Shard 收集面板、Starite Vision 和家庭头像板。
- 首次进入世界显示一次“Lily 的考验”叙事卡（烂苹果 → Lily 石化 → 帮助他人收集 Starite），随后显示“基础入门”纸片卡，按“写词 → 召唤 → 帮助 NPC → 获得 Starite”建立原版核心循环，完成状态写入存档，之后直接回到自由探索。
- 顶部进度栏显示 Lily 解咒进度与石化/解咒状态；收集 3 个 Starite 后开放世界地图，收集 60 个 Starite 后显示揭示 Edgar 考验的胜利卡，收集 106 个 Starite 后显示独立的全收集家庭档案卡，可继续探索或打开世界地图。
- 多设备适配：电脑/手机/平板多尺寸自适应（`Scale.RESIZE` + DOM overlay 响应式 + `env(safe-area-inset-*)`），触屏设备自动显示虚拟摇杆（左下）与跳跃/交互按钮（右下），桌面端键盘体验不受影响；横竖屏切换时固定屏背景层与 UI 浮层自动重布局

## 技术栈

| 层 | 技术 |
|---|---|
| 引擎 | Phaser 4.2.1（WebGL2 + 内置 Matter Physics） |
| 构建 | Vite 6 |
| 语言 | TypeScript 5（strict 全开） |
| 测试 | Vitest 2（node 环境，纯逻辑核心） |
| 路径别名 | `@` → `./src` |

## 运行

```bash
npm install        # 安装依赖（含 phaser）
npm run dev        # 启动开发服务 → http://localhost:5173
npm run build      # 类型检查 + 生产构建（dist/）
npm run preview    # 预览生产构建
npm test           # 运行纯逻辑单测
```

一键启动（自动检测并安装缺失依赖后启动开发服务）：

- macOS/Linux：`./start.sh`
- Windows：双击 `start.bat`

项目内置技能：`harness`，用于高不确定性、跨边界开发中的自主探索、垂直切片、真实验证与对抗审核；定义见 `.agents/skills/harness/`。

## 玩法

- **笔记本**：屏幕底部输入框，输入词回车生成物体（中/英均可，候选补全保留命中的别名）；输入框为空时按回车关闭笔记本。例：`狗` / `dog` / `飞行的紫色的章鱼`。
- **形容词**：输入"基础词 + 形容词"组合，如`大的狗`、`飞行的紫色的章鱼`；选中实体后输入纯形容词（如`燃烧`）回车即对该实体施加。词典现覆盖动物/元素/物品/食物/武器/植物/载具/工具多类基础词（660 独立词条），以及体型/颜色/材质/状态/行为五类形容词（123，如`glassy`），英文复合词支持连字符、空格和大小写规范化，可组合出大量变体。
- **规则交互**：火点燃可燃物（连锁燃烧）并引爆爆炸物、爆炸按范围伤害实体，容器可收纳碰撞物并从对象面板取出，水灭火、锋利武器切断绳子、冷源冻水成冰、武器伤害生物、带电物体电击肉体；词条生命值按原版常见对象数据驱动，受伤对象上方显示四段局部生命圆点；effect 的真实破坏结果会进入挑战判定，草地新增“清除挡路绳索”挑战，切断或射击均可完成。
- **关卡**：41 个主区域（丛林草地 / 洞穴 / 雪原 / 沙漠 / 火山 / 故事书堡 / 齿轮站及新增的回文星窟、句法站等区域），经区域衔接传送；每个区域绑定独立生成的远板/近板背景和唯一 `bgm`，世界地图与区域传送门都按 `unlockedLevels` 执行 Starite 门槛，不能通过传送门绕过顺序解锁。首个自由探索区保留固定位置的 Edwin 农场引导 NPC、井/木箱地标与三阶段善意任务（食物→水→清除木箱），并绑定家庭头像目录，把 Lily 主线动机落到首次可操作帮助上。回文星窟与句法站是可回返的 cave overworld，各自拥有独立 NPC、固定地标、双出口和唯一 authored challenge 指纹；关卡共用规则/词条能力，但区域背景、音乐与挑战内容不复用。每个存档按种子随机生成预生成物体、NPC 位置和环境装饰；故事关键 NPC 可保持固定锚点，设置页刷新题目种子即可重新生成一套布局。挑战由 NPC 发起，支持多阶段、区域、顺序和状态条件，authored challenge 不设置实体数量门槛，满足条件得 Starite/碎片。有未完成挑战的 NPC 头顶浮动金色 "!" 徽章提示；玩家靠近触发对话气泡时该 NPC 暂停移动，气泡稳定可读。
- **难度**：在设置页统一配置难度档（基础/进阶/大师）与分档标准（游戏内等级档 / 词频启发式档），进入关卡时直接生效，无需逐关选择。题库 1345 题，三层结构：情境多答案题（NPC 第一人称陈述困境如"好冷""天黑""饿""渴""怪物挡路"，不点名目标，2~6 个语义关联答案任一即过关）/ 词条覆盖单答案题（660 词条每个至少一道故事化题面）/ 形容词组合题（如"红色的鸟""凶猛的狗"，严格校验输错颜色/行为不算过关），按所选难度过滤后由存档种子随机抽取分配给本关 NPC。难度设置持久化到存档。题目种子可在设置页查看/输入/一键刷新，换种子重置所有关卡题目进度（保留关卡解锁与自制物体）。
- **选关**：标题页"选择关卡"进入关卡选择界面，纸上路线/主题节点展示全部关卡，按 Starite 门槛顺序解锁；顶部提供「解锁全部」按钮，可一次开放全部关卡访问权。每张卡片右下角提供「重置」按钮清空本关进度重玩，右上角「重置所有」按钮一键清空全部进度（挑战/Starite/碎片/Object Shard），自制物体保留。进度状态持久化到存档。
- **对象操作面板**：点击实体后展开，可直接使用笔记本、创建物体、给当前实体添加形容词，或打开物体编辑器；点击 Maxwell 会打开装备与骑乘面板，展示手持/背部/坐骑关系和八个穿戴部位，并支持单项/全部解除（面板实时刷新不打断按钮点击）；点击空白处关闭。
- **物体编辑器/魔法背包**：按 `O` 打开物体编辑器，或从对象操作面板进入；选中实体后按 `Q/E` 向左/右旋转；组合"基础词条 + 中英文名称/别名 + 形容词 + 颜色 + 多部件锚点"保存为自定义物体，支持编辑、复制、删除，之后输入该名或从背包即可生成并以刚性连接跟随。`B` 打开背包，支持搜索、收藏、最近使用和频次排序。
- **玩家控制**：左键点击地面移动，点击实体后 Maxwell 会靠近并执行默认使用；左键点击 Maxwell 或 HUD 头像打开装备与骑乘面板，键盘 `I` 也可切换；左键拖动物体可操控/投掷，拖到 Maxwell 或 NPC 身上会按穿戴部位、手持或坐骑关系自动处理，物品保留自身朝向并与宿主朝向合成最终翻面，穿戴物同步镜像身体部位锚点，右键已装备到 NPC 的物品可解除；手持生物的自主行为与物理碰撞会暂停/隔离以避免反向拖动 Maxwell；`F` 统一交互（拾取/装备/骑乘/下坐骑/释放），`G` 保留释放快捷键；手枪按枪柄而非精灵中心绑定到手部，朝向随 Maxwell 左右转身同步，避免手持时偏移或旋转；右键对准远程武器开火，没有远程武器时仍可作为桌面便捷跳跃；`C`/小键盘 `5` 重置相机，小键盘 `2/4/6/8` 平移观察，`+/-` 与鼠标滚轮缩放。触屏设备自动显示虚拟摇杆与跳跃/交互/开火按钮，可在设置中关闭。手持远程武器、穿戴飞行/跳跃能力与骑乘坐骑时能力同时保留，切换关卡会安全解除旧世界附着。受伤/死亡后自动重生。地图预生成的 NPC、树、石头等实体不阻挡玩家（穿行无阻），玩家生成的物体与之正常碰撞以驱动规则。
- **辅助面板**：`M` 世界地图（完整 41 个区域按序排列，窄屏自动改为可滚动网格）、`J` Merit Board、`O` Object Shard 收集、`V` 切换 Starite Vision、`K` 家庭头像。家庭头像按已完成挑战槽解锁 40 个兄弟姐妹，60 Starite 解锁 Lily，106 Starite 且完成 217 个 Object Shard 后解锁父母；选中的头像会写入存档并替换玩家外观。Vision 开启蓝色滤镜并实时标记未完成的 Starite/碎片任务与 NPC；面板可在关卡切换时同步刷新。
- **暂停**：窗口失去焦点或按 `ESC` 自动暂停游戏（物理、规则引擎、行为系统、音乐全部停转，纸片风全屏遮罩提示），点击遮罩或再按 `ESC` 恢复。

## 架构分层

```
src/
├── core/            领域核心层（纯 TS，零 Phaser 依赖，可单测）
│   ├── lex/         双语闭集分词
│   ├── rules/       声明式规则引擎 + TagSet + TagIndex + effects
│   ├── data/        词典/形容词/规则/关卡 JSON/题库 + 存档
│   ├── entity/     Entity 抽象接口
│   ├── game/        GoalSystem（挑战评估）
│   └── types/       纯类型
├── engine/          Phaser 集成层
│   ├── scenes/      WorldScene（调度链）
│   ├── physics/     Matter 适配（碰撞/Constraint/Query）
│   └── render/      sprite atlas 渲染器（registry/EntityGraphics/spriteRenderers）+ Camera + Environment（分层视差，背景程序化绘制）+ VectorDraw（纯工具函数）
├── game/            游戏逻辑层（桥接 core 与 engine）
│   ├── Entity.ts    GameEntity（持 GameObject + Matter body）
│   ├── Spawner.ts PlayerController.ts MousePicker.ts LevelRandomizer.ts ObjectLibrary.ts
│   ├── BehaviorSystem.ts LevelManager.ts DialogSystem.ts QuestMarker.ts
│   ├── AdjectiveSystem.ts ObjectEditor.ts
├── ui/              DOM 浮层（Notebook/Hud/ProgressPanel/SpeechBubble/Backpack/WorldMap/MeritBoard/ObjectShardBoard/StariteVision/...，涂鸦纸片风 + 自托管无衬线字体 + 内联 Lucide 图标）
├── fx/              视觉增强（Filter/粒子/SpawnFx 生成动效/自定义 shader）
└── util/            日志（console，英文）
tests/               纯逻辑单测
```

核心层（`src/core`）零 Phaser 依赖，可在 node 环境单测；游戏层（`src/game`）桥接 core 与 engine；UI 用 DOM overlay 叠在 Phaser canvas 之上（中文 IME 必需）。

## 设计原则

- 奥卡姆/YAGNI/KISS/DRY：core 层只声明并实现真正用到的字段/触发器/effect
- 依赖注入消除全局单例（旧项目 effectDeps 全局变量已重构）
- 日志：console 封装 + 英文
- 领域用语见 `CONTEXT.md`

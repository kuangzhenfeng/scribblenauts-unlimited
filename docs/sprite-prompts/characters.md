# 角色与生物 Sprite 提示词

> 参见 [README.md](README.md) 获取基础风格前缀与工作流说明。renderer===id：每物种一张独立 sprite atlas（单帧 idle），不再共用家族 renderer。颜色由图本身表达，不用 setTint。

## 主角

### maxwell（8帧 · 512×96px）
```
《涂鸦冒险家无限》2D卡通游戏精灵图集，3像素粗黑色轮廓，平涂阴影，鲜艳高饱和度颜色，白色背景，无投影，水平排列8帧，每帧精确64×96像素，所有帧角色比例一致。
角色：男孩Maxwell，头戴红色锯齿冠罗纹帽，身穿蓝白横条纹毛衣，深蓝裤子，黑色鞋子，大圆眼睛，背后有棕色背包带。
帧布局：第1帧=站立待机；第2-5帧=步行循环（左脚向前、过渡、右脚向前、过渡）；第6帧=跳跃（膝盖弯曲上抬，双臂上举）；第7帧=下落（双臂水平展开，腿部后飘）；第8帧=死亡（身体倾斜15度，眼睛呈X形）。
```

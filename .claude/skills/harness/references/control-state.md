# 控制状态模板

精简任务纯靠上下文，不落文件；标准/深入任务或多依赖步骤才用以下模板。除非用户要求或仓库已有规定，否则不要在仓库中新增跟踪文件。

## 任务控制状态

```markdown
结果：
- 可观察结果：
- 授权边界与非目标：

完成门槛：
- [ ] 门槛 — 决定性证据

当前切片：
- 结果与证伪条件：

已验证事实与假设：
- 事实 — 证据位置
- 假设 — 置信度 — 证伪条件

延后发现与风险：
- 发现 — 延后原因或风险 — 缓解措施
```

出现重大新发现、预测失败、范围变化或门槛完成后更新。上下文压缩后从该状态继续，不得重新开始。

## 切片简报

```markdown
结果：
范围（所属文件/边界）：
聚焦验证与真实运行面检查：
完成证据与证伪条件：
```

不要因为第一个切片正在等待例行检查就启动与其重叠的实现切片。只有当契约已稳定且集成负责人明确时，才并行开展独立取证或互不重叠的切片。

## 子代理简报

```text
目标：回答一个有界的不确定问题，或实现一个有界的改动。
所属范围：指定独占文件所有权，禁止无关编辑。
允许操作：默认只读；显式列出允许的任何编辑或外部命令。
停止条件：问题已回答，或已证明存在具体阻塞；未经授权不得扩大范围。
```

实现代理须声明可能写入所属源码之外的命令和路径（格式化器、生成器、包管理器、快照、缓存、构建产物）。审核代理不得接收预期答案或疑似缺陷，只接收原始产物。把代理报告视为待验证主张，集成前检查证据。
